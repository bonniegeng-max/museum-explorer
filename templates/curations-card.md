### 给 LLM 的三阶段字段打通规则

1. **展品 key 唯一**：阶段1 为每件展品定稳定 `key`（`S01`…），策展卡、观展单、手帐 JOURNAL_DATA 三处用同一 key；改排序只动 No.，不动 key。
2. **勾选自动承接**：用户勾选的展品 key 列表 → 阶段2 观展单只渲染这些展品（含同 key）→ 阶段3 手帐 exhibits 数组收录已打卡（`visited:true`）展品，`no` 字段沿用 key 对应序号。
3. **行中新增展品**：现场发现策展卡没列的重点展品，观展单追加时给新 key（续 `S{n+1}`），手帐一并收录。
4. 三阶段共用展品字段：`name / era / location / look(拍照位) / feeling(感受)`——策展卡提供前四项，观展单补 `feeling` 与勾选，手帐据 `visited` 汇总。
