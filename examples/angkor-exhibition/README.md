# 真实案例：遇见吴哥窟

这是 `museum-explorer` skill 的第一次完整 pilot，基于用户在 2026-08-30（展览闭展日）于「遇见博物馆·北京798馆」的真实看展记录。

## 案例背景

- **展览**：遇见吴哥窟——柬埔寨国家博物馆文物特展
- **地点**：北京 · 798 遇见博物馆
- **展期**：2026-05-01 ~ 2026-08-30（已闭展）
- **现场记录**：用户在观展过程中于豆包连续提问 6 个展品相关问题，本 skill 将其整理为「行中即时问答区」。

## 本目录产物

| 文件 | 说明 |
|---|---|
| `session.md` | 会话状态：阶段进度、打卡记录、决策记录 |
| `curations-card.md` | 行前策展卡（复盘补做版，含来源核验表） |
| `on-site-checklist.md` | 行中观展单（含 6 轮真实问答） |
| `journal.html` | 行后电子手帐（7 页 A4，可直接打印/截图） |

## 数据亮点

- 8 件重点展品，其中 4 件有现场打卡与感受记录
- 塞建陀、穆卡林加因仅有「观展实录单源」，在核验表中诚实标注【待核实】
- 8 枚统一形制的 SVG 印章，纹样抽象提取自展品本身

## 与根目录 skill 的关系

- 模板来自 `templates/`
- 规范来自 `references/`
- 展品数据已回写入 `data/yujian-angkor-2026.json`
- 预览图在 `preview/angkor-*.png`
